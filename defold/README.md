# «Латунная ночь» — Defold

Первый этап переноса на **Defold 1.14.1 и Lua**. Откройте `defold/game.project` в редакторе Defold и запустите проект. В ангары можно вернуться через экран результатов. Управление — WASD, стрелки или перетаскивание по арене. Пауза — Esc или кнопка вверху.

## Что перенесено

- Пять героев, кадры ходьбы, стартовое оружие, три устава и локальные открытия героев.
- Десятиминутная арена с поминутными волнами, налётами, кольцами с проходом, шестью элитами и Смотрителем.
- Инвентарь 4+4, пять семейств оружия, шесть артефактов, опыт, смена предложений, исключение предмета и пять эволюций из шкатулок. После вылазки виден урон по оружию.
- Симуляция использует фиксированный шаг 60 Гц, отрисовка интерполирует позиции. Враги, эффекты и добыча повторно используют узлы интерфейса. Источники графики собраны в атлас.

Ящики с полевыми находками из веб-версии ещё предстоит перенести. Профиль этого прототипа хранится локально отдельно от предыдущей Android-сборки.

## Проверки и этапы

1. **Перенос игрового цикла.** Проверяются начало боя, уровень, смена выбора, шкатулки и финал в 10:00. Для тестов симуляции запустите `luajit tests/smoke.lua` из этой папки.
2. **Читаемость и баланс.** Следующий этап — отдельно проверить окна уклонения у таранов и миномётов, темп первой эволюции, прохождение Ники и сбор обычного опыта после налётов. Сравнивать результаты на одинаковых начальных числах генератора.
3. **Развитие контента.** После проверки на телефоне вернуть ящики и добавить арену с другой геометрией. Поддерживать доступность обязательных сигналов при плотной орде.

## Сборка Android

Используйте `bob.jar` версии 1.14.1 и JDK 25. Из папки `defold/`:

```sh
java -jar bob.jar --archive --platform arm64-android --architectures arm64-android --variant release --bundle-format apk --bundle-output build/android-apk build bundle
```

В локальной тестовой сборке Bob создаёт отладочный ключ, если ключ не передан. Для публикации потребуется отдельная релизная подпись.
