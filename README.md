# Латунная ночь

Стимпанк-рогалик на выживание для телефона. Текущая разработка — **Defold 1.14.1 / Lua**, проект в [`defold/`](defold/README.md), версия 0.15.0. Откройте `defold/game.project` в Defold. Инструкции сборки Android и результаты проверок находятся в документации этой папки.

Ниже сохранена документация предыдущего прототипа на Godot 4.6 / GDScript.

## Запуск

Установите стандартную редакцию Godot 4.6, импортируйте `project.godot` и нажмите **F5**. Для запуска из терминала выполните `godot --path .`.

Управление на компьютере — WASD или стрелки. На сенсорном экране коснитесь арены и ведите палец. Оружие атакует автоматически. Смотритель появляется на 09:00. Нужно победить его и дожить до 10:00.

## Устройство проекта

- `scripts/catalog.gd` — данные героев, предметов и волн.
- `scripts/run_state.gd` — симуляция забега. Вызывается из `_physics_process`, отдельно от отрисовки.
- `scripts/arena.gd` — игровой экран, ввод, отрисовка арены, анимация и интерфейс.
- `assets/` — атласы оригинальных спрайтов и иконок из веб-прототипа. Спрайты выводятся с фильтрацией nearest.

Анимация героя использует `AnimatedSprite2D`. Позиция героя и камеры интерполируется движком, позиции врагов и снарядов — от предыдущего состояния симуляции. Проект рассчитан на портретный режим и рендерер Compatibility.

## Мобильные сборки

Для Android в Godot нужны шаблоны экспорта, JDK и Android SDK. Экспорт iOS выполняется с macOS и Xcode. Проект запускается в редакторе, экспортные сборки и производительность на физических устройствах предстоит проверить.

- [Экспорт Android](https://docs.godotengine.org/en/4.6/tutorials/export/exporting_for_android.html)
- [Экспорт iOS](https://docs.godotengine.org/en/4.6/tutorials/export/exporting_for_ios.html)
